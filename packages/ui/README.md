# @bolerish/ui

React components for the bolerish design system.

See the [official documentation](https://ui.bolerish.com) for installation and usage.
Coding agents can start with [llms.txt](https://ui.bolerish.com/llms.txt) and the
[documentation MCP](https://ui.bolerish.com/docs/mcp) for the existing agent workflow,
component references and original examples.

Check installed package versions before using bundled references. Installed
TypeScript declarations take precedence over a documentation snapshot.
